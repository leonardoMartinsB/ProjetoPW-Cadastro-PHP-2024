## ✨ Sobre o Projeto

Este projeto é um sistema de **cadastro de funcionários** desenvolvido como uma das primeiras experiências com **Programação Web no lado do servidor (Back-end)**, utilizando a linguagem **PHP**.

O principal objetivo foi criar um formulário funcional capaz de coletar e processar dados, enviando-os para o servidor. A estrutura utiliza o PHP para lidar com a lógica de back-end, enquanto o **Bootstrap** foi empregado para garantir uma interface visualmente agradável e responsiva.

🔹 Principais destaques:

* ✅ Desenvolvimento **Full-stack** (Front-end e Back-end) em um projeto simples
* ✅ Estrutura de código organizada com **HTML, CSS e PHP**
* ✅ Design responsivo e moderno graças ao uso do **Bootstrap**
* ✅ Demonstração prática do processamento de formulários com PHP

## 🛠️ Tecnologias Utilizadas

* **HTML5** → Estrutura do formulário
* **CSS3** → Estilização básica da página
* **PHP** → Lógica de back-end para processamento dos dados do formulário
* **Bootstrap** → Framework de CSS para design responsivo e componentes
